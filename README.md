🎵 Sistema Musical

📋 Sobre o Projeto

O Sistema Musical é um projeto desenvolvido para organizar e gerenciar artistas e músicas em uma plataforma simples e intuitiva. O sistema possui telas de login, menu principal, cadastro de artistas, cadastro de músicas e biblioteca musical.

O objetivo do projeto é aplicar conhecimentos de desenvolvimento web utilizando HTML e CSS, criando uma interface organizada, moderna e responsiva.

🚀 Funcionalidades

🔐 Tela de Login: acesso ao sistema por meio de usuário e senha.

🏠 Menu Principal: navegação entre as principais áreas do sistema.

🎤 Cadastro de Artistas: formulário para inserir nome, gênero musical, país e foto do artista.

🎶 Cadastro de Músicas: permite inserir título, artista, álbum, gênero, link do YouTube, capa e letra da música.

🎼 Biblioteca Musical: exibição das músicas cadastradas em formato de tabela.

🔍 Filtros: campos para pesquisar músicas por título, álbum, artista e gênero.

📱 Design Responsivo: adaptação das páginas para diferentes tamanhos de tela.

🛠️ Tecnologias Utilizadas

HTML5: estruturação das páginas.

CSS3: estilização, cores, layouts, tabelas e formulários.

Flexbox: organização dos elementos.

CSS Grid: criação de grades para formulários e menus.

Media Queries: adaptação para dispositivos móveis.
